# MineSafe V4 — our own PCBs and sensor boards (planned)

**Status: planned.** V3 is still being calibrated ([docs/v3.md](v3.md)). V4 starts once every sensor has been checked and calibrated on the breadboard.

## Why
In V3 every unit is a development board plus sensor modules joined with jumper wires. That was right for finding the circuit, but it is the main source of trouble on the bench — loose I²C wires, a missing 4.7 kΩ pull-up, power rails that do not reach a sensor — and it is too large and fragile to wear underground. V4 replaces the breadboards with PCBs we design ourselves.

## Proposed boards (draft — to be finalised by the team)
| Board | Replaces | On the board |
|---|---|---|
| **Body-unit main board** | ESP32-C6 / S3 DevKit + jumper wires | ESP32 module, USB-C charging + Li-ion protection, 3.3 V regulator, SOS button, alert LED, battery connector |
| **Body sensor board** | MPU6050, BMP180, MAX3010x, DS18B20, HW-827 modules | IMU, pressure sensor, pulse-oximeter, skin-temperature probe connector, I²C pull-ups fitted on the board |
| **Repeater board** | XIAO C6 + MQ module + AHT module + buzzer | ESP32-C6 module with u.FL antenna, MQ heater supply and 5 V → 3.3 V divider, AHT20, buzzer driver, power-bank / DC input |
| **Entry-station board** | XIAO S3 Sense + PN532 + OLED wiring | carrier for the XIAO S3 Sense, PN532 header, OLED header, three buttons, mounting holes |

## Proposed plan
1. Freeze the V3 pin maps and circuit after calibration (`docs/wiring.md`).
2. Draw schematics and PCB layouts (KiCad), design review with our guide.
3. Order prototype boards, assemble, run the same test sketches (`firmware/tests/*`).
4. Enclosures for the body unit (wearable) and the repeaters.
5. Full trial with the PCB units, demo video, final report.

Firmware and the hub stay the same — only the pin maps change.
