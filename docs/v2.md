# MineSafe V2 — ESP-NOW network + control-room website

**Body ESP and repeaters talk over ESP-NOW; a proper website on the laptop runs the control room.**
Code snapshots: git history v0.1 → v1.0 (snapshot: branch [`version/v2.0`](https://github.com/Manas-36/MINESAFE/tree/version/v2.0), same as `version/v1.0`) · Previous: [V1](v1.md) · Next: [V3](v3.md)

```
Body ESP ── ESP-NOW ──► REP-03 ──► REP-02 ──► REP-01 (main) ── Wi-Fi HTTP ──► Admin website (laptop)
   ▲                                             │                                │
   └──────────── alert in beacons ◄──────────────┴──────────── alert in reply ◄───┘
Entry station (RFID) ── Wi-Fi ──► Admin website ◄── Wi-Fi ── Phone camera (entry photo / test worker)
```

## What V2 added
| Part | V2 |
|---|---|
| Radio | **ESP-NOW** between body unit and repeaters — no router, ~1 ms per hop, 54-byte packet every second |
| Repeater chain | Self-forming: beacons every second, parent = neighbour with fewest hops, channel search 1–13, duplicate filter; main repeater posts to the hub over Wi-Fi |
| Body unit | ESP32-S3: MPU6050, BMP180, DS18B20, MAX30100/30102 (+ HW-827), SOS button, alert LED — drivers written in-house |
| Website (admin hub) | Flask on the laptop: **Live** cards, **Map** with GPS-free tracking, **Gas & air**, **Register workers** (medical card), **Entry check**, **Kit check (AI)**, **Network**, **Incident log**, one-click **ALERT** |
| Entry station | XIAO ESP32-C6 + PN532 + OLED: writes / reads NTAG215 gear tags (helmet, vest, pants, shoes) |
| Photo check | Phone camera page → photo + scanned tags → admin approves and pairs a body unit; optional YOLOv8 kit check |
| Gas | MQ sensor on each repeater, ppm estimate per gas, automatic alarm + local buzzer |
| Location | Steps × step length along the gyro heading, snapped to tunnels, reset at repeaters; height from pressure |
| Alerts | Admin ALERT → every repeater buzzes, every body LED lights, within ~3 s |
| Testing | Phone acts as a worker from any repeater's test page; simulator and demo walker need no hardware |

## Tested on hardware
PHONE-01 and BODY-01 reached the website through the repeater chain; SOS and fall turned the card red; ALERT made the repeater buzz and lit the body LED.

## Why we moved on (lessons → V3)
| Limitation in V2 | Fix in V3 |
|---|---|
| Entry photo needed a second person with a phone | Entry station gets its **own camera** (XIAO ESP32-S3 Sense) + PHOTO button |
| Only one real worker on the map for demos | **Mock worker** (ESP32-C6 + MPU6050) |
| No wiring drawings | **Schematics** for every unit |
| Mixed repeater boards | All repeaters on **XIAO ESP32-C6** |
